## 线程与数据边界

- Worker 只负责目录遍历、指纹计算和媒体元数据读取。
- Worker 不访问 UI，也不复用主线程 SQLite 连接。
- 扫描结果通过 Qt queued signal 回到 `QQMusic` 主线程，再批量写入本地模型/数据库。
- 退出时先取消并等待扫描线程，再关闭数据库。

## 已知限制

- 当前无登录/云同步服务，因此主题同步仅保留本地接口和持久化；网络失败回退将在 P2 实现。
- 独立桌面歌词不符合现有产品视觉，暂缓到后续体验设计明确后再评估。
- 扫描使用 Qt 多媒体后端读取元数据，具体格式支持取决于系统编解码器。
- `MusicScanner` 仅在任务结束或取消时汇总结果，后续可增加可恢复任务队列。

## 面试回顾

- 为什么 UI 不直接扫描：目录遍历和媒体元数据解析属于不可预测 I/O，必须隔离到 Worker。
- 如何保证数据库安全：SQLite 连接始终留在主线程，Worker 只传递值对象。
- 如何处理文件移动：以文件大小和首尾内容计算 SHA-1 指纹，发现旧路径失效时更新 URL 而不丢失收藏/历史。
